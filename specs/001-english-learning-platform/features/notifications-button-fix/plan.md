# Implementation Plan: Fix Notifications Button in Teacher Dashboard

**Branch**: `001-english-learning-platform` | **Date**: 2026-04-12 | **Spec**: `./spec.md`
**Input**: Feature specification from `specs/001-english-learning-platform/features/notifications-button-fix/spec.md`

## Summary

The teacher dashboard (`/en/dashboard/teacher`) has two broken notification buttons:
1. A decorative `🔔` emoji button in `DashboardLayout` with no click handler
2. A hardcoded duplicate button in the teacher hero section with fake badge count

Fix: Replace the DashboardLayout button with the existing `<NotificationBell />` component (already used in `RoleBasedNav`), and remove the duplicate from the teacher page hero.

**Constraints**: Must not break student/admin dashboard views
**Scale/Scope**: 3 roles, 1 layout file, 1 page file
